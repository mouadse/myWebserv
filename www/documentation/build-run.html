Build and Run

One Makefile, clear flags.

The Makefile enforces -std=c++98 and ships both development and production flags depending on the DEBUG variable.

Build

make
make DEBUG=1

Debug mode enables extra warnings and AddressSanitizer where available. Production builds use -O3 and LTO.

Run

./webserv
./webserv config/demo.conf

The default configuration is config/demo.conf. The server stops gracefully on SIGINT or SIGTERM.

Test quickly

curl -i http://127.0.0.1:8085/
curl -i -X POST --data 'hello' http://127.0.0.1:8085/upload
curl -i -X DELETE http://127.0.0.1:8085/delete/file.txt

Configs to explore

  • config/demo.conf includes upload and CGI routes.
  • config/example.conf shows multi-server setup.
Build logic is in Makefile, entry point in src/main.cpp.

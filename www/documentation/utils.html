Utilities

Small tools that keep the core clean.

The utilities in src/utils are designed to keep the rest of the codebase focused on HTTP and networking behavior.

Logger

Logger supports levels (DEBUG, INFO, WARN, ERROR), console color output, and optional file logging. Debug mode is toggled by Logger::enableDebugMode.

Helpers

  • toString overloads for common types.
  • escapeHtml used for directory listing output.
  • findServerByFd routes epoll events.

PathUtils

joinPaths normalizes slashes and prevents accidental double separators when building file paths.

FileCache

A small LRU cache for static files, used by GET requests.

  • Max entries: 100
  • Max file size: 1 MB
  • Max total size: 50 MB

ParserUtils

Shared helpers for configuration parsing: strict integer parsing, whitespace trimming, status code names, and body size parsing.

Utilities live in src/utils and src/config.

HTTP

Incremental parsing, strict validation.

HTTPRequest is a state machine that consumes data as it arrives. It supports both content-length bodies and chunked transfer encoding.

Parsing states

The parser moves through START_LINE, HEADERS, BODY, and then either DONE or ERROR. 

ParseState
  START_LINE -> HEADERS -> BODY -> DONE
  ERROR on invalid input

Validation rules

  • Allowed methods: GET, POST, DELETE.
  • HTTP version must be HTTP/1.1.
  • Max URI length: 8192 bytes.
  • Max header block: 32 KB.
  • Chunked and Content-Length cannot both be set.
Request headers are normalized to lowercase keys for lookups.

Body handling

For chunked transfer encoding, the parser tracks chunk size and content using BodyParseState. For fixed bodies, it reads until Content-Length is satisfied.

Responses

HttpResponse builds status lines, headers, and body buffers. setBody automatically updates Content-Length. File bodies can be streamed by setting setFileBody. 

response.setStatus(200, "OK");
response.setHeader("Content-Type", "text/html");
response.setBody("Hello");

Notes on HEAD

RequestHandler treats HEAD like GET and strips the body, but the request parser currently only accepts GET, POST, and DELETE. Supporting HEAD requires updating HTTPRequest validation.

HTTP parsing is implemented in src/http/HTTPRequest.cpp and response building in src/http/HTTPResponse.cpp.
